# SwipeShrink: Photo Cleaner — Support & Legal

This repository contains the official public support and legal website for **SwipeShrink: Photo Cleaner**.

## Pages

- `index.html` — support and legal landing page
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Use
- `support.html` — support, troubleshooting, FAQ, and contact information
- `styles.css` — shared responsive visual design
- `favicon.svg` — site icon

Support email: [myskyocean2024@gmail.com](mailto:myskyocean2024@gmail.com)

## Publishing

The site is a dependency-free static website intended for GitHub Pages. Publish from the repository root on the `main` branch through **Settings → Pages → Build and deployment → Deploy from a branch**, then select `main` and `/ (root)`.

Expected routes after GitHub Pages is enabled:

- Home: `https://mcleung-888.github.io/swipeshrink-photo-cleaner-support/`
- Privacy: `https://mcleung-888.github.io/swipeshrink-photo-cleaner-support/privacy.html`
- Terms: `https://mcleung-888.github.io/swipeshrink-photo-cleaner-support/terms.html`
- Support: `https://mcleung-888.github.io/swipeshrink-photo-cleaner-support/support.html`

Do not treat an expected URL as live until it has been verified after publication.

## Maintenance

Legal wording must remain synchronized with the app’s actual behavior. Review and update the Privacy Policy and Terms before releasing changes that introduce or materially alter analytics, advertising, accounts, cloud uploads, subscriptions, remote servers, tracking, or third-party SDKs. Support documentation should also be updated when user-visible workflows change.

No build system is required. Open any HTML file directly or serve the repository root with a basic local static server for development.
